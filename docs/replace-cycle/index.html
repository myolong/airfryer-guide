생활용품 교체 주기

수세미는 언제 바꾸지? 물건 이름을 입력하면 흔히 권장되는 교체 주기와 '이럴 땐 바로 교체' 신호가 나옵니다. 휴대폰 달력에 교체일을 적어 두면 잊지 않아요.

물건교체 주기이럴 땐 바로 교체오래 쓰는 관리법
칫솔욕실약 3개월솔이 옆으로 벌어졌을 때, 감기 등을 앓고 난 뒤쓰고 나서 털어 세워 말리기. 칫솔끼리 닿지 않게
수건욕실1~2년빨아도 냄새가 남, 뻣뻣하고 물을 잘 못 빨아들임한 번 쓰면 세탁, 섬유유연제는 조금만(흡수력이 떨어짐)
샤워볼·때수건욕실1~2개월냄새·변색·곰팡이쓰고 나서 헹궈 욕실 밖 바람 통하는 곳에 걸기
욕실 슬리퍼욕실6개월~1년바닥이 미끄럽거나 뒷면 곰팡이세워서 말리기. 곰팡이 청소는 곰팡이·물때 메뉴 참고
변기 솔욕실3~6개월솔이 눕거나 냄새가 남쓰고 나서 물기를 털고 통에 물이 고이지 않게
샤워기 필터욕실1~2개월 (제품 표시)필터 색이 진하게 변함가족 수·물 사용량이 많으면 더 빨리
수세미주방2~4주냄새, 미끈거림, 색이 변함쓰고 나서 꼭 짜서 세워 말리기. 젖은 채로 두면 세균이 늘어남
행주주방1~2개월삶아도 냄새·얼룩이 남음매일 빨아 말리고 주 1회 삶거나 과탄산에 담그기
도마주방플라스틱 6개월~1년, 나무는 상태 보고칼자국이 깊게 패여 검게 변함, 곰팡이고기·생선용과 채소용 나눠 쓰기. 세워서 말리기
코팅 프라이팬주방1~2년코팅이 벗겨지거나 음식이 계속 눌어붙음철 수세미·금속 뒤집개 쓰지 않기, 빈 팬 센 불 가열 피하기
고무장갑주방1~2개월구멍, 안쪽 냄새벗은 뒤 뒤집어 말리기
밀폐용기 (플라스틱)주방상태 보고 (보통 수년)흠집·변색이 심하거나 뚜껑 패킹이 늘어남패킹은 분리해 씻어 말리기
칼주방갈아서 계속 사용손잡이가 흔들리거나 날이 이가 빠짐한두 달에 한 번 숫돌이나 칼갈이로
베개 솜침실·생활1~2년 (메모리폼 2~3년)반으로 접었을 때 펴지지 않음, 누런 얼룩·냄새베개 커버는 주 1회 세탁
이불 솜침실·생활솜 이불 3~5년, 상태 보고뭉치거나 꺼져서 보온이 안 됨겨울 이불 세탁·보관은 옷 정리 메뉴 참고
매트리스 커버·토퍼침실·생활커버 상태 보고, 토퍼 2~3년꺼짐·냄새·얼룩커버는 한두 달에 한 번 세탁, 토퍼는 세워서 말리기
매트리스침실·생활약 7~10년가운데가 꺼지거나 스프링 소리, 아침에 허리가 아픔3~6개월마다 위아래를 돌려 쓰기
운동화침실·생활자주 신으면 약 1년밑창이 한쪽으로 닳거나 쿠션이 꺼짐두 켤레를 번갈아 신으면 오래 감
소화기침실·생활제조일로부터 약 10년 (제품 표시)압력 게이지 바늘이 초록색 밖현관·주방 근처 잘 보이는 곳에
에어컨 필터가전 소모품2주~1개월마다 청소찢어지거나 먼지가 빠지지 않음물로 씻어 그늘에서 완전히 말리기
공기청정기 필터가전 소모품6개월~1년 (제품 표시)필터 교체 알림, 냄새앞쪽 프리필터는 2주마다 먼지 털기
정수기 필터가전 소모품제품 표시 (보통 몇 개월~1년)물맛·냄새가 달라짐렌탈이면 방문 관리 일정 확인
청소기 먼지 필터가전 소모품세척형은 주기적 세척, 교체형 6개월~1년흡입력이 약해지고 냄새먼지통은 쓸 때마다 비우기
가습기 진동자·필터가전 소모품제품 표시물때가 지워지지 않음물통은 2~3일마다 세척
