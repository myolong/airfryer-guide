삶은 달걀·면 삶는 시간표

반숙은 몇 분? 소면은 언제 건지지? 달걀과 면 종류를 입력하면 삶는 시간과 요령이 바로 나옵니다.

종류시간넣는 시점요령
달걀 반숙(흐르는 노른자)달걀6~7분끓는 물꺼내자마자 찬물에 담그기
달걀 촉촉한 반숙달걀8분끓는 물노른자 가운데만 말랑
달걀 완숙달걀10~12분끓는 물15분 넘기면 노른자 겉이 초록빛
달걀 반숙(찬물부터)달걀끓고 나서 5~6분찬물깨질 걱정이 적은 방법
달걀 완숙(찬물부터)달걀끓고 나서 10~12분찬물물에 소금·식초 조금
메추리알달걀3~4분끓는 물찬물에 식힌 뒤 비비듯 까기
소면국수·면3~4분끓는 물끓어오르면 찬물 반 컵, 두 번 반복
중면국수·면5~6분끓는 물소면보다 두꺼워 시간을 늘리기
칼국수 생면국수·면5~7분끓는 국물겉 밀가루를 털고 넣기
우동 생면·냉장면국수·면2~3분끓는 물이미 익힌 면이라 풀어지면 완성
냉동 우동국수·면1~2분끓는 물해동하지 말고 바로 넣기
냉면(생면)국수·면40초~1분끓는 물건져서 얼음물에 바로 헹구기
메밀국수(건면)국수·면4~5분끓는 물찬물에 비벼 전분 씻어내기
쫄면국수·면3~4분끓는 물가닥가닥 풀어서 넣기
당면국수·면6~8분끓는 물30분 불리면 3~4분으로 단축
쌀국수(건면)국수·면불린 뒤 30초~1분끓는 물미지근한 물에 30분 불리기
라면국수·면4~5분끓는 물물 500~550ml, 꼬들면은 3분
스파게티파스타8~10분끓는 소금물포장 시간에서 1분 빼면 알덴테
펜네·푸실리파스타10~12분끓는 소금물소스와 1분 더 볶을 것 감안
링귀네·페투치네(건면)파스타9~11분끓는 소금물면수를 한 컵 남겨 두기
생파스타파스타2~3분끓는 소금물떠오르면 거의 다 익은 것

찾는 항목이 없어요. 다른 이름으로 검색해 보세요.

달걀은 냉장고에서 바로 꺼낸 중란~대란 기준입니다. 면은 제품 포장에 적힌 시간이 있다면 그쪽을 우선하세요.

삶는 시간은 일반적인 가정용 냄비와 가스레인지 기준의 참고값입니다. 화력, 냄비 크기, 물 양에 따라 1~2분 차이가 날 수 있습니다.

삶는 시간 가이드

  • 반숙·완숙 달걀 삶는 시간, 깨지지 않고 잘 까지는 법반숙과 완숙 달걀 삶는 시간을 끓는 물·찬물 시작 기준으로 정리했습니다. 달걀이 깨지지 않게 하는 법, 껍질 잘 까지는 요령, 보관 기간도 알려 드립니다.
  • 소면 삶는 법, 불지 않고 쫄깃하게 삶는 시간과 요령잔치국수·비빔국수용 소면과 중면 삶는 시간, 찬물 붓는 이유와 타이밍, 면이 불지 않게 헹구는 법과 1인분 양을 정리했습니다.
  • 파스타 면 삶는 법, 소금 양과 알덴테 시간 맞추기스파게티, 펜네, 링귀네 등 파스타 면 삶는 시간과 소금물 비율, 알덴테 맞추는 법, 면수 활용과 1인분 양을 정리했습니다.
  • 건면·생면·냉동면 차이와 면 삶기 기본 원칙건면, 생면, 냉동면이 어떻게 다른지와 각각 삶는 방법, 물 양과 헹굼 여부, 남은 면 보관법까지 면 요리의 기본 원칙을 정리했습니다.
