가전 청소 주기 가이드

  • 에어컨 필터 청소 방법과 주기, 퀴퀴한 냄새 없애기벽걸이·스탠드 에어컨 필터를 직접 청소하는 방법과 2주 주기를 권하는 이유, 에어컨 냄새의 원인과 송풍 건조 습관, 전문 세척이 필요한 시점을 정리했습니다.
  • 세탁기 세탁조 청소 방법, 통돌이·드럼 주기와 순서통돌이와 드럼세탁기의 세탁조 청소 주기와 방법, 세제통·고무패킹·배수 필터 청소, 빨래에 검은 찌꺼기가 묻어 나올 때 대처법을 정리했습니다.
  • 냉장고 청소와 정리법, 냄새 없애고 전기요금 아끼기냉장고 내부 선반과 고무패킹 청소 방법, 냄새 제거 요령, 칸별 정리 원칙, 뒷면 먼지 청소로 전기요금을 아끼는 방법을 정리했습니다.
  • 주방 후드 필터 청소, 찌든 기름때 쉽게 녹이는 법주방 레인지 후드의 기름 필터를 베이킹소다와 뜨거운 물로 불려 청소하는 방법, 청소 주기, 후드 본체와 팬 관리 요령을 정리했습니다.
  • 가습기 세척 방법과 주기, 물때·세균 걱정 없이 쓰기가습기 물통을 매일 관리하는 방법과 2~3일마다 하는 세척 순서, 물때 제거, 가습기 살균제를 쓰지 않아야 하는 이유와 보관법을 정리했습니다.
