곰팡이·물때 청소법

곰팡이는 락스 계열, 하얀 물때는 산성(구연산·식초) 세제가 기본입니다. 청소할 곳이나 얼룩 이름을 입력하면 쓰는 세제와 순서가 나옵니다. 락스와 산성 세제는 절대 함께 쓰지 마세요.

장소·얼룩쓰는 세제청소 순서주의·예방
욕실 실리콘 검은 곰팡이욕실락스(젤 타입) 또는 곰팡이 제거제물기 닦기 → 젤 락스를 실리콘에 바르거나 휴지를 덮고 락스 적시기 → 랩으로 덮어 2~3시간 → 물로 헹구기실리콘 속까지 번져 안 지워지면 실리콘을 새로 쏘는 게 답. 청소 뒤 물기 닦기
타일 줄눈 곰팡이욕실락스 희석액 (제품 표시 비율)희석한 락스를 뿌리고 10~20분 → 칫솔·줄눈 솔로 문지르기 → 물로 헹구기다 지운 뒤 줄눈 코팅제를 바르면 다시 덜 생김
욕실 천장 곰팡이욕실락스 희석액 + 밀대고글·마스크 쓰고 밀대에 키친타월을 감아 희석액 묻혀 닦기 → 깨끗한 물걸레로 한 번 더스프레이를 위로 뿌리면 눈에 떨어짐. 샤워 후 환풍기 1~2시간
세면대·수전 하얀 물때욕실구연산수 또는 식초구연산 1큰술 + 물 200ml 뿌리기 → 키친타월 덮고 30분 → 수세미로 닦고 헹구기하얀 물때는 석회(알칼리)라 산성으로 녹임. 대리석·천연석에는 쓰지 말기
샤워부스 유리 물때욕실구연산수 + 스퀴지구연산수 뿌리고 키친타월로 덮어 30분 → 부드러운 수세미 → 물로 헹군 뒤 스퀴지로 물기 제거샤워 후 스퀴지로 물기만 밀어도 물때가 거의 안 생김
샤워기 헤드 막힘욕실구연산수 담그기헤드를 분리해 구연산수(물 1L + 구연산 2큰술)에 1~2시간 담그기 → 칫솔로 구멍 문지르기물줄기가 약해지면 석회가 쌓인 것. 한 달에 한 번
변기 누런 물때·띠욕실구연산 또는 산성 변기 세정제물을 내리고 물 높이 선에 구연산 가루 뿌리기 → 휴지 덮고 1시간 → 솔로 문지르고 물 내리기변기 락스와 산성 세정제를 번갈아 쓸 때는 물을 여러 번 내린 뒤에
욕실 배수구 물때·냄새욕실베이킹소다 + 식초 → 뜨거운 물머리카락 걷기 → 베이킹소다 반 컵 → 식초 1컵 붓고 30분 → 뜨거운 물로 흘리기막힘이 심하면 배수구 클리너 사용. 락스와 함께 쓰지 않기
욕실 슬리퍼·욕실화 물때욕실락스 희석액 담그기희석액에 10~20분 담갔다가 솔로 문지르고 헹군 뒤 세워서 말리기바닥에 눕혀 두면 뒷면에 곰팡이. 걸어서 말리기
샤워커튼 곰팡이욕실산소계 표백제 또는 락스 희석떼어서 따뜻한 물에 표백제 풀고 30분 담그기 → 세탁기 섬세 코스샤워 후 커튼을 펴 두어야 접힌 곳에 곰팡이가 안 생김
싱크대 배수구 물때주방베이킹소다 + 식초 또는 과탄산거름망 꺼내 솔질 → 베이킹소다·식초 부어 30분 → 뜨거운 물 흘리기주 1회. 음식물 거름망은 매일 비우기
싱크대 실리콘 곰팡이주방주방용 락스 젤물기 닦기 → 젤 바르고 랩 덮어 1~2시간 → 물로 충분히 헹구기식기에 닿지 않게 그릇을 치우고 작업. 청소 뒤 환기
스테인리스 개수대 물자국주방구연산수 또는 식초구연산수 뿌리고 5분 → 부드러운 수세미 → 헹구고 마른 행주로 닦기철 수세미는 흠집이 나서 물때가 더 잘 낌
전기포트 하얀 물때주방구연산물 가득 + 구연산 1큰술 넣고 끓이기 → 1시간 두었다 버리기 → 물만 한 번 더 끓여 버리기석회라 몸에 해롭진 않지만 맛이 달라짐. 한 달에 한 번
도마 곰팡이주방주방용 락스 희석 또는 과탄산희석액에 30분 담그기 → 솔로 문지르고 충분히 헹구기 → 햇볕에 세워 말리기칼자국이 깊고 검게 변하면 교체
냉장고 고무 패킹 곰팡이주방주방용 락스 희석 또는 알코올면봉·칫솔에 묻혀 홈을 닦기 → 물걸레 → 마른 행주로 물기 제거냉장고 전체 청소는 가전 청소 메뉴 참고
창틀 레일 곰팡이·먼지창문·베란다중성세제 → 곰팡이는 락스 희석마른 먼지 먼저 솔·청소기 → 물 뿌려 불리기 → 칫솔·나무젓가락에 키친타월 감아 닦기 → 곰팡이 자리만 희석액배수 구멍이 막히면 물이 고여 곰팡이. 구멍을 뚫어 두기
창문 고무 패킹 곰팡이창문·베란다젤 락스젤을 패킹에 바르고 랩 덮어 1~2시간 → 물걸레로 여러 번 닦기겨울 결로가 원인. 아침에 물기 닦고 환기
결로 생긴 창문 주변 벽창문·베란다곰팡이 제거제 (벽지용)마른 솔로 포자 털지 말고 제거제를 뿌려 두드리듯 닦기 → 드라이어 약하게 말리기가구를 벽에서 5~10cm 띄우고 하루 2~3번 환기
베란다 벽·천장 곰팡이창문·베란다락스 희석액 → 곰팡이 방지 페인트창 열고 희석액 뿌려 30분 → 솔로 문지르고 물걸레 → 완전히 말린 뒤 곰팡이 방지 페인트빨래를 베란다에 말리면 습기가 차 곰팡이가 잘 생김
베란다 바닥 물때·이끼창문·베란다과탄산 또는 락스 희석 + 솔가루를 뿌리고 물 조금 → 30분 → 솔로 문지르고 물로 씻어 배수구로아래층 배수와 이어지니 물을 한꺼번에 많이 쓰지 않기
방충망 먼지·곰팡이창문·베란다중성세제 물 + 스펀지바깥쪽에 신문지 대고 안쪽에서 스펀지로 닦기 → 물걸레로 한 번 더떼어서 욕실에서 샤워기로 씻어도 됨
벽지 곰팡이벽·생활용품벽지용 곰팡이 제거제 또는 알코올제거제를 뿌리고 10분 → 키친타월로 두드려 닦기 → 드라이어로 말리기얼룩이 넓거나 벽 속이 젖어 있으면 누수 확인. 세입자는 집주인에게 먼저 알리기
옷장·붙박이장 안 곰팡이벽·생활용품알코올(소독용 에탄올)옷을 모두 꺼내고 알코올을 뿌려 닦기 → 문 열어 하루 말리기 → 제습제 넣기곰팡이 핀 옷은 따로 세탁. 옷 보관은 옷 정리 메뉴 참고
매트리스 아래·침대 프레임벽·생활용품알코올 + 햇볕·통풍매트리스를 세워 바닥 확인 → 프레임은 알코올로 닦기 → 매트리스는 통풍시키기바닥에 매트리스만 깔면 아래에 습기가 차 곰팡이. 깔판 사용
실리콘 주방용품·물병 곰팡이벽·생활용품과탄산 또는 베이킹소다 담그기뜨거운 물에 과탄산 1큰술 풀고 30분 담그기 → 솔로 닦고 헹구기빨대·뚜껑 패킹은 분리해서 완전히 말려 보관

락스(염소계)는 구연산·식초·산성 세제, 암모니아 세제와 섞으면 유독 가스가 생깁니다. 다른 세제를 쓴 자리는 물로 충분히 헹구고 시간을 두고 쓰세요. 희석 비율은 제품 표시가 우선입니다.

청소 방법은 일반적인 가정 기준의 참고 정보입니다. 세제는 제품 설명서를 따르고, 환기와 고무장갑·마스크를 꼭 챙기세요. 벽 속까지 번진 곰팡이나 누수는 관리사무소나 전문 업체에 문의하세요.

곰팡이·물때 가이드

  • 욕실 곰팡이 제거법, 실리콘·줄눈 검은 곰팡이 지우는 순서욕실 실리콘과 타일 줄눈, 천장에 생긴 검은 곰팡이를 락스 젤과 랩으로 지우는 순서, 안전 수칙, 실리콘이 안 지워질 때 대처와 다시 안 생기게 하는 습관을 정리했습니다.
  • 하얀 물때 제거법, 수전·샤워부스·전기포트 구연산으로 닦기세면대 수전, 샤워부스 유리, 샤워기 헤드, 전기포트에 생기는 하얀 물때(석회)를 구연산과 식초로 녹이는 방법과 비율, 쓰면 안 되는 재질을 정리했습니다.
  • 창틀·베란다·벽지 곰팡이 청소법, 겨울 결로 곰팡이 막는 법겨울 결로로 생기는 창틀 레일, 창문 고무 패킹, 베란다 벽, 벽지와 옷장 곰팡이를 장소별로 지우는 방법과 결로를 줄이는 환기·가구 배치 요령을 정리했습니다.
