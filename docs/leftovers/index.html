남은 음식 보관 가이드

  • 남은 음식 보관 원칙, 국·반찬 냉장 며칠까지 먹어도 될까만들어 둔 국·찌개와 반찬을 안전하게 보관하는 기본 원칙, 식히는 법과 2시간 규칙, 냉동해도 되는 음식과 안 되는 음식, 다시 데우는 요령을 정리했습니다.
  • 배달 음식 남았을 때 보관법, 치킨·피자·족발 냉장 며칠과 맛있게 데우기남은 치킨, 피자, 족발·보쌈, 중식, 떡볶이, 회의 냉장 보관 기간과 냉동 가능 여부, 에어프라이어·팬·전자레인지로 맛있게 데우는 방법과 배달 용기 보관 시 주의점을 정리했습니다.
