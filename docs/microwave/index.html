전자레인지 가이드

  • 전자레인지로 골고루 데우는 법과 위험한 음식 정리전자레인지로 밥·국·반찬을 겉만 뜨겁고 속은 차갑지 않게 골고루 데우는 요령과, 달걀 폭발·물 끓어 넘침처럼 꼭 알아야 할 주의사항을 정리했습니다.
  • 전자레인지 용기 사용 가능 여부, 유리·플라스틱·배달용기 정리전자레인지에 넣어도 되는 용기와 안 되는 용기를 재질별·브랜드별(코렐, 글라스락, 락앤락, 이케아 등)로 정리했습니다. 배달 용기, 종이컵, 랩, 알루미늄 호일, 스티로폼 사용법까지 한눈에 확인하세요.
  • 전자레인지 출력(W)별 시간 환산법, 700W·1000W·1200W포장지에 적힌 전자레인지 시간이 우리 집 전자레인지 출력과 다를 때 쓰는 간단한 환산법과 환산표, 우리 집 전자레인지 출력 확인 방법을 정리했습니다.
