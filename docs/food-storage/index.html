식재료 보관 가이드

  • 채소·과일 보관법, 냉장고에 넣을 것과 실온에 둘 것대파, 양파, 감자, 고구마, 양배추, 상추, 버섯, 사과, 바나나까지 채소·과일별 냉장·실온 보관법과 오래 두는 요령, 소분해서 얼리는 방법을 정리했습니다.
